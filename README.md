في هذا المشروع، قمت بتطوير تطبيق 'متجر الأناقة' بأسلوب فني وتصميم وردي متناسق. يدمج التطبيق بين صفحة تسجيل دخول (Login) صممتها باستخدام TextFields، ونظام تنقل (Stack Navigation) بين الشاشة الرئيسية وشاشة التفاصيل. قمت بربط الشاشات مع تمرير البيانات واستقبال رسالة تأكيد عبر الـ SnackBar، مع الاعتماد على واجهات مستخدم رقيقة تعكس هوية المتجر."
​الأدوات المستخدمة:
​Navigation: Navigator (Push & Pop).
​UI: TextFields, ElevatedButton, SnackBar, Gradient.
